# TraceRAG

Status: foundation — estágio inicial.

O TraceRAG tem como objetivo ser um sistema RAG local-first, fundamentado em evidências, para documentação pública de metrologia.

Somente fontes públicas serão utilizadas. A seleção e as condições de uso de cada fonte serão verificadas em etapas futuras.

Esta versão contém apenas a estrutura inicial e os contratos documentais do repositório. Nenhuma funcionalidade de RAG está implementada.
